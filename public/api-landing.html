API Reference

Four Production-Ready Endpoints

Each endpoint is credit-gated, rate-limited, and fully documented. Pass your API key via the x-api-key header.

POST /v1/prompts/compile 1 credit

Compiles and optimizes raw prompts into dense, production-ready versions using AI. Removes fluff, enforces imperative style, and compresses context.

curl -X POST https://api.prompthouse.dev/v1/prompts/compile \ -H "x-api-key: ph_evo_your_key" \ -H "Content-Type: application/json" \ -d '{"prompt": "Please help me write a function that sorts an array"}'
POST /v1/apps/blueprint 2 credits

Generates a full-stack application architecture blueprint from a name and feature list. Returns file structure, technology recommendations, and module hierarchy.

curl -X POST https://api.prompthouse.dev/v1/apps/blueprint \ -H "x-api-key: ph_evo_your_key" \ -H "Content-Type: application/json" \ -d '{"name": "TaskFlow", "features": ["auth", "dashboard", "payments"]}'
POST /v1/themes/evolve 1 credit

Evolves a base color into a complete UI color palette with CSS variables, semantic token names, and dark/light mode variants.

curl -X POST https://api.prompthouse.dev/v1/themes/evolve \ -H "x-api-key: ph_evo_your_key" \ -H "Content-Type: application/json" \ -d '{"baseColor": "#6366f1"}'
POST /v1/code/audit 1 credit

Audits source code for production readiness. Flags TODO/FIXME markers, console logging, debugger statements, and missing ESM exports. Returns a 0–100 score.

curl -X POST https://api.prompthouse.dev/v1/code/audit \ -H "x-api-key: ph_evo_your_key" \ -H "Content-Type: application/json" \ -d '{"code": "export function greet() { return \"Hello\"; }"}'
